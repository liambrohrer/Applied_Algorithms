# Applied Algorithms

A collection of Python implementations and exercises in graph algorithms. The examples cover graph representation, traversal, connectivity, bipartite graphs, matching, and network flow.

## Topics

- **Graph representations:** convert between adjacency matrices and adjacency lists.
- **Graph traversal:** use breadth-first search (BFS) and depth-first search (DFS) to explore graphs and measure traversal depths.
- **Connectivity:** find weakly and strongly connected components, including with Kosaraju’s algorithm.
- **Bipartite graphs:** test whether a graph is bipartite and find matchings using augmenting paths.
- **Network flow:** use Dinic’s algorithm and node splitting to find vertex-disjoint paths.
- **Compatibility matching:** model laptop-to-outlet assignments as a bipartite matching problem, with BFS to determine adapter reachability.

## Running the programs

The examples are standalone Python scripts. Run a script with Python 3:

```bash
python3 filename.py
```

Provide input in the format expected by that script. Check the source file for its input structure and any sentinel value that marks the end of input.

## Note

These programs are intended for algorithm practice and study. They demonstrate different approaches to graph problems; input assumptions and edge cases may vary between scripts.
